====================================================================
  SKALA 날씨 대시보드 - 발표 자료
  (Vue 3 + Pinia + Vue Router 기반 실시간 날씨 웹앱)
====================================================================

────────────────────────────────────────────────────────────────
1. 프로젝트 개요 (1분)
────────────────────────────────────────────────────────────────
- 교재(day1~day3) 실습 내용을 기반으로, OpenWeatherMap 실시간 API를
  연동한 "실전 날씨 대시보드"로 확장 제작
- 목표: 교재 기능 구현에 그치지 않고, 실제 서비스처럼 쓸 수 있는
  완성도(UI/UX, 애니메이션, 실데이터, 반응형)를 갖추는 것
- 참고: 동일 과제를 수행한 타 수강생 사이트 3곳을 스크린샷 분석하여
  공통적으로 기대되는 기능(대기질, 예보, 내 위치, 다크모드 등) 파악 후 반영

────────────────────────────────────────────────────────────────
2. 교재 학습 내용 매핑 (이 프로젝트에 실제로 쓰인 곳) (2분)
────────────────────────────────────────────────────────────────
- Composition API (ref/reactive/computed/watch)
  → weatherStore, configStore, favoriteStore, 모든 화면의 상태 관리
- 컴포넌트 분리 & Props/Emits
  → WeatherCard/CityCard, FavoriteToggle, WeatherIcon 등 재사용 컴포넌트
- Lifecycle Hook (onMounted)
  → 화면 진입 시 날씨 데이터 로드, geolocation 결과 반영
- Vue Router (동적 라우트, 지연 로딩, Navigation)
  → '/', '/regions', '/weather/:cityId', '/stats', '/about', 404 처리
- Pinia (state/getters/actions)
  → weatherStore(API 연동 핵심), configStore(단위 전환), favoriteStore(즐겨찾기)
- Axios 비동기 통신
  → OpenWeatherMap Current/Forecast/Air Pollution/Geocoding API 전부 axios로 호출

────────────────────────────────────────────────────────────────
3. 교재 대비 "새로 추가한" 기능 (핵심 발표 포인트, 5분)
────────────────────────────────────────────────────────────────
[데이터 측면]
① 실시간 API 연동
   - 기존: 도시 6곳의 날씨가 컴포넌트에 하드코딩된 mock 데이터
   - 개선: OpenWeatherMap 실시간 API로 완전 대체, 6개 화면 데이터를
     Pinia store 하나로 공유 (중복 호출 방지 - ensureLoaded 패턴)

② 5일치 예보 + 시간별 예보 (신규)
   - 상세 페이지에서 "오늘 시간별 기온" area 차트 + "5일 최고/최저"
     range 차트를 ApexCharts로 시각화

③ 대기질(AQI) 정보 (신규)
   - 미세먼지(PM10) / 초미세먼지(PM2.5) / 이산화질소(NO2) + 등급 뱃지
   - 기존 "미세먼지: 보통" 같은 고정값을 실제 Air Pollution API로 대체

④ 내 위치(Geolocation) 기반 홈 화면 (신규)
   - 브라우저 위치 권한으로 현재 위치 날씨를 자동으로 큰 히어로 카드에 표시
   - 권한 거부/실패 시 서울로 자동 폴백 + 안내 배너

⑤ 자유 도시 검색 (Geocoding API, 신규)
   - 기존 6개 도시 고정 → 검색창에 아무 도시나 입력해 전 세계 도시 추가 가능
   - 추가한 도시는 localStorage에 저장되어 새로고침해도 유지

[UX/재미 요소]
⑥ 오늘의 불쾌지수 카드 (기상청 공식 기반 계산, 신규)
⑦ 한 줄 준비물 추천 ("우산을 챙기세요", "마스크를 챙기세요" 등 조건부 문구, 신규)
⑧ 일출·일몰 프로그레스 바 (신규)
⑨ 날씨/시간대에 따라 자동으로 바뀌는 배경 그라디언트 (신규)
⑩ 비/눈 오는 지역은 카드 위에 실제 Canvas 파티클(빗방울/눈송이) 연출 (신규)
⑪ 다크 모드 지원 (전체 화면, 신규)
⑫ 카드/섹션 진입 애니메이션, 페이지 전환 트랜지션 (신규)

[정보구조 개선]
⑬ "내 위치"(홈)와 "다른 지역 탐색"(지역별 날씨)을 별도 화면으로 분리
   → 기존엔 홈 하나에 모든 도시가 나열되던 구조를 목적에 맞게 재설계

────────────────────────────────────────────────────────────────
4. 사용한 라이브러리 (3분)
────────────────────────────────────────────────────────────────
- axios              : 모든 REST API 통신 (기존에도 사용, 확장 적용)
- @vueuse/core        : useGeolocation(내 위치), useDark(다크모드),
                        useDebounceFn/onClickOutside(검색창), useStorage(영속 저장)
- @vueuse/motion      : v-motion 디렉티브로 카드/히어로 진입 애니메이션
- apexcharts
  + vue3-apexcharts   : 시간별/5일 예보 애니메이션 차트 (그라디언트 area,
                        range bar), 라이트/다크 테마 대응
- @lucide/vue         : 아이콘 라이브러리 - 이모지를 전부 대체
                        (번들 최적화를 위해 필요한 아이콘만 named import
                         → 아이콘 청크 692KB → 59KB로 절감)

※ 신규 API 엔드포인트 (모두 OpenWeatherMap 무료 티어)
   - /data/2.5/weather        (현재 날씨 - 기존에도 사용)
   - /data/2.5/forecast       (5일/3시간 예보 - 신규)
   - /data/2.5/air_pollution  (대기질 - 신규)
   - /geo/1.0/direct          (도시 검색 - 신규)
   - /geo/1.0/reverse         (좌표 → 지역명 역지오코딩 - 신규)

────────────────────────────────────────────────────────────────
5. 아키텍처에서 신경 쓴 부분 (3분 - 기술 디테일 어필 포인트)
────────────────────────────────────────────────────────────────
- weatherStore를 entries(id → 데이터) 구조로 재설계
  → 6개 고정 도시 + 검색으로 추가한 커스텀 도시 + 내 위치('me')를
    동일한 구조로 관리해서 화면 어디서든 재사용 가능
- fetchCurrent(가벼움) vs fetchDetail(현재+예보+대기질 병렬 Promise.all)
  로 API 호출을 분리 → 목록 화면은 가볍게, 상세 화면만 무겁게 호출
- ensureLoaded/isLoaded 가드로 화면 전환 시 중복 API 호출 방지
- Vite 환경변수 이슈 대응: .env 키를 VITE_ 접두사로 통일해
  클라이언트 번들에 안전하게 노출되도록 수정
- 다크모드는 CSS 커스텀 프로퍼티(디자인 토큰) 기반으로 설계해
  컴포넌트 코드 변경 없이 테마 전환

────────────────────────────────────────────────────────────────
6. 트러블슈팅 (짧게 - "실제로 겪은 문제" 어필, 1~2분)
────────────────────────────────────────────────────────────────
- 통계 페이지에서 데이터가 비어있는 첫 렌더 시점에 배열 reduce()가
  "Reduce of empty array" 런타임 에러 발생
  → Playwright로 콘솔 에러를 직접 잡아내어 로딩 조건 재설계로 해결
- lucide 아이콘을 `import * as` 로 통째로 불러와 번들이 692KB까지 비대화
  → 실제 쓰는 아이콘만 named import 하도록 수정해 92% 절감

────────────────────────────────────────────────────────────────
7. 기술 스택 한눈에 (발표 멘트용 간단 요약)
────────────────────────────────────────────────────────────────
※ 시연 전/후에 "이 프로젝트는 이런 기술로 만들었습니다" 하고
   짧게 짚고 넘어갈 때 그대로 읽어도 되는 버전입니다.

  "날씨 데이터는 OpenWeatherMap API를 사용해서, 현재 날씨뿐 아니라
   5일 예보·대기질·도시 검색까지 전부 실시간으로 받아왔습니다.
   프론트엔드는 Vue 3와 Pinia로 구성했고, UI 쪽은 아이콘 라이브러리로
   lucide, 차트는 ApexCharts, 애니메이션과 다크모드 같은 유틸리티는
   VueUse를 사용해서 완성도를 높였습니다."

한 줄 요약표:
  구분           | 사용 기술                         | 역할
  --------------|-----------------------------------|--------------------------------
  날씨 데이터 API | OpenWeatherMap                    | 현재날씨/5일예보/대기질/도시검색
  프레임워크      | Vue 3 (Composition API) + Vite    | 전체 앱 구조
  상태 관리      | Pinia                              | 날씨/즐겨찾기/단위 설정 전역 관리
  라우팅         | Vue Router                          | 5개 화면 + 동적 경로(:cityId)
  HTTP 통신      | Axios                               | 모든 API 호출
  UI 아이콘      | @lucide/vue                         | 이모지 대신 사용한 아이콘 세트
  차트/시각화    | ApexCharts (vue3-apexcharts)        | 시간별/5일 예보 애니메이션 차트
  유틸리티       | VueUse (@vueuse/core, /motion)      | 내 위치, 다크모드, 검색 디바운스,
                 |                                     | localStorage 저장, 진입 애니메이션
  스타일링       | 커스텀 CSS 디자인 시스템             | 라이트/다크 테마, 글래스모피즘 카드,
                 | (CSS 커스텀 프로퍼티)                | 날씨별 배경 그라디언트

한 문장 버전 (시간 없을 때):
  "날씨 API는 OpenWeatherMap, UI는 Vue 3 + Pinia 기반에 lucide 아이콘과
   ApexCharts 차트, VueUse 유틸리티 라이브러리를 조합해서 만들었습니다."

────────────────────────────────────────────────────────────────
8. 데모 시연 순서 제안
────────────────────────────────────────────────────────────────
1) 홈 화면 - 내 위치 자동 감지, 불쾌지수/대기질/일출일몰 위젯 → 다크모드 토글
2) 지역별 날씨 - 도시 검색으로 새 도시 추가 → 즐겨찾기 토글/필터
3) 상세 페이지 - 시간별/5일 예보 차트, (비/눈 오는 도시가 있다면) 파티클 효과
4) 통계 페이지 - 기온 랭킹
5) (선택) 개발자 도구 콘솔 - API 통신 로그 확인
